# İçerik derecelendirmesi (IARC anketi) — cevaplar

Play Console → Politika ve programlar → Uygulama içeriği → **İçerik derecelendirmesi** → Başlat. E-posta: `saawanco@gmail.com` (IARC yazışmaları buraya gelir).

Kaynak: <https://support.google.com/googleplay/android-developer/answer/188189> · <https://support.google.com/googleplay/android-developer/answer/9898843>

Anket metni zaman zaman değişir; aşağıdaki cevaplar uygulamanın içeriğini anlatır, soru farklı yazılmışsa aynı ilkeyle cevapla. Yanlış beyan uygulamanın kaldırılmasına yol açabilir; içerik değişirse anketi yeniden doldur.

## Kategori

**Yardımcı Program, Verimlilik, İletişim veya Diğer** *(Utility, Productivity, Communication, or Other / “All other app types”)*. Oyun, sosyal ağ, haber ya da eğitim uygulaması değil.

## Cevaplar

| Konu | Cevap | Not |
|---|---|---|
| Şiddet, kan, korku öğeleri | **Hayır** | Yalnızca hava durumu ve kıyafet çizimleri. |
| Cinsellik, çıplaklık | **Hayır** | Kıyafet çıkartmaları insan figürü içermez. |
| Küfür, kaba dil, kaba mizah | **Hayır** | |
| Uyuşturucu, alkol, tütün | **Hayır** | |
| Kumar, gerçek parayla ya da benzeri bahis | **Hayır** | |
| Ayrımcılık, nefret sembolleri | **Hayır** | |
| Kullanıcılar birbiriyle etkileşebiliyor veya içerik paylaşabiliyor mu? *(Users interact / exchange content)* | **Hayır** | Sohbet, yorum, profil paylaşımı yok. “Paylaşım kartı” yalnızca Android’in paylaşım ekranını açar; uygulama içinde kullanıcılar arası iletişim yok. |
| Kullanıcının konumunu diğer kullanıcılarla paylaşıyor mu? *(Shares user location with other users)* | **Hayır** | Konum yalnızca hava durumu için sunucuya gider, başka kullanıcıya gösterilmez. |
| Dijital ürün satın alımı *(Digital purchases)* | **Hayır** | Uygulama içi satın alma yok. Ortaklık linkleri dış mağazalarda fiziksel ürünlere gider; bağış linki Play uygulamasında yok. |
| Kısıtlamasız internet erişimi / web tarayıcısı ya da arama motoru mu? *(Unrestricted internet)* | **Hayır** | Uygulama yalnızca kendi sayfasını gösterir (APK’nın içinden). Ortaklık linkleri, kaynak linkleri ve gizlilik politikası cihazın tarayıcısında açılır; uygulama içinde serbest gezinme yok. Yer arama bir web arama motoru değil, harita veritabanında yer arar. |
| Reklam *(sorulursa)* | **Evet, reklam içerir** | Reklamlar derecelendirmeye dahil edilmez ama “uygulamanın içeriğinden belirgin şekilde daha olgun olmamalı.” Reklam beyanı ayrıca: `ads-declaration.md`. |
| Nazi sembolleri vb. yasaklı semboller | **Hayır** | |

## Beklenen sonuç

Bütün içerik soruları “Hayır” olduğundan derecelendirme en düşük yaş seviyesinde çıkması beklenir (ör. PEGI 3, ESRB Everyone, USK 0). Kesin sonucu anketin özet sayfası gösterir; gönder demeden kontrol et.

## Reklamların derecelendirmeyle uyumu (yapılacak)

- **AdMob:** Uygulamalar → Ne Giysem? → Engelleme kontrolleri → **Maksimum reklam içeriği derecelendirmesi**: *G* ya da *PG*. Hassas kategorileri (kumar, flört, alkol vb.) engelle.
- **AdSense (web):** Engelleme kontrolleri → Hassas kategoriler’de aynı kategorileri engelle.
